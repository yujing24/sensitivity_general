# Sensitivity_general

R codes for "Sensitivity analysis for trials with irregular and informative visit times: generalized outcome mean models and data-driven sensitivity parameter selectiond"

* data_analysis: R codes for the case study.
* simulation_inference: R code implementing the influence function-based augmented inverse intensity-weighted estimation and inference procedures. The implementation supports multiple outcome types, including continuous (identity link), binary (logit link), and count (log link) outcomes.
* simulation_selection: R code implementing Algorithms 1-3 for identifying the plausible range of the sensitivity parameters and constructing the corresponding confidence sets.
